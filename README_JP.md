## 主な機能

### 💰 支出記録
- 日付・金額・カテゴリ・支払方法・メモを入力して支出を記録します。
- 月別カレンダービューとリストビューを併用できます。
- 消費区分（大分類 / 小分類）と支払方法タグを自由に設定できます。

### 🔁 固定費管理
- 家賃・サブスクリプション・保険料など毎月繰り返される固定費を別途管理します。
- 月別固定費合計と通常支出合計を分けて残高を計算します。
- 今月のデータが空の場合は固定費タブを開くたびに先月の項目コピーを提案します。拒否時に**今月は今後表示しない**を選択でき、コピー後の金額は確認が必要になるよう0に初期化します。

### 📈 収入管理
- 月収を登録し、予算に対する支出状況を把握します。

### ✈️ 旅行管理
- 旅行モードがオンになると、ホーム・支出記録画面の記録ボタンが緑色の**旅行の支出を記録**に変わります。
- 設定の**アプリの背景**で標準の単色または4種類のグラデーションを選べます。旅行モードに関係なくアプリ全体に適用され、再起動後も最初の画面から維持されます。
- 旅行を削除すると、確認後にその旅行のすべての支出を**普段**に変更し、旅行情報を削除します。支出の金額と内容は保持されます。
- 旅行期間・予算を登録し、旅行モードで記録した支出を旅行ごとにまとめて確認できます。
- 旅行カードで名前・期間・状態と総支出、予算使用率、残り予算または超過額を確認できます。予算未設定の場合はカードから設定できます。
- 旅行前・旅行中・旅行後の支出、1日平均、交通費・宿泊費、予算使用率を確認できます。

### 🏷️ 支出区分アイコン
- システム標準の支出区分は、名前とともに意味を表すアイコンを表示します。アイコン情報はタグのメタデータとCSVバックアップに保存され、旧形式のデータには支出区分コードに応じた標準アイコンが自動適用されます。

### 📊 分析レポート
- `fl_chart` ベースのビジュアライゼーションで支出パターンを一目で確認できます。
  - カテゴリ別 / 支払方法別の支出割合（円グラフ）
  - 日別支出推移（折れ線グラフ）
  - 最高・最低支出日の自動分析
- 特定の月または日付範囲を選択して絞り込み表示できます。
- 期間別分析と旅行別分析を切り替えられます。

### 🗂 データ管理
- 検索条件（支払方法・期間・支出区分・支出小区分・内容・備考）でレコードをフィルタリングします。
- 検索結果を**一括選択 → 削除**または**タグ一括変更**でき、過去の支出を特定の旅行へ一括で紐付けられます。
- 2,000 件以上の大量データも遅延レンダリング（SliverList）でスムーズに表示します。

## データ移行（エクスポート / インポート）

機種変更やデータのバックアップを行いたいときに使用します。

### エクスポート手順

1. **データ管理**メニューから**エクスポート**を選択します。
2. エクスポートする**期間**を選択します（全期間 / 特定月 / 日付範囲）。
3. **認証キー**を入力します（復元時に同じキーが必要です）。
4. **エクスポート**ボタンを押すと、署名付きの `.csv` ファイルが生成されます。ファイル本文は暗号化されません。

バックアップには支出・固定支出・収入に加え、旅行情報、旅行に紐づく支出、タグ、通知、アプリの背景設定が含まれます。月・期間バックアップには、選択した支出が参照する旅行だけが含まれます。
5. ファイルをメール・クラウド・USB など好きな方法で保存します。

> ファイルはメールアドレスと認証キーの組み合わせで署名されます。  
> 署名が一致しない場合は復元がブロックされますので、**キーは必ずメモしておいてください。**

### インポート手順

1. **データ管理**メニューから**インポート**を選択します。
2. 保存しておいた `.csv` ファイルを選択します。
3. エクスポート時に使用した**認証キー**を入力します。
4. **インポート**ボタンを押すと、既存データとのマージなしに全データが復元されます。

> ⚠️ インポートは現在のデータを**上書き**します。事前に現在のデータをエクスポートしてバックアップしておいてください。

旅行情報が含まれていない旧形式のバックアップもインポートでき、その場合は旅行一覧と旅行の紐付けが空の状態で復元されます。新形式で旅行参照が壊れているファイルは、現在のデータを置き換える前に拒否されます。

## PDF レポート出力

月次締め・確定申告・家族への共有など、さまざまな用途で PDF レポートを生成できます。

### 含めることができるセクション

| セクション | 内容 |
|-----------|------|
| 概要サマリー | 総収入 / 総支出 / 残高 / 固定費合計 |
| カテゴリ別支出 | カテゴリ・小分類別の金額と割合 |
| 支払方法別支出 | 決済手段別の金額と割合 |
| 支出 Top 10 | 最大の支出項目 10 件 |
| 固定費詳細 | 固定費全リスト |
| 支出明細（付録） | 対象期間の全取引履歴 |
| グラフ | カテゴリ円グラフ、日別支出折れ線グラフ |

### 出力手順

1. **データ管理**メニューから**レポート生成**を選択します。
2. レポートに含める**セクション**にチェックを入れます。
3. 集計する**期間**を設定します。
4. 必要に応じて**パスワード**を設定します（PDF 閲覧時に入力を要求）。
5. **生成**ボタンを押すと PDF が作成され、**共有**ボタンで他のアプリに渡せます。
6. 生成したレポートは**レポート一覧**に保存され、いつでも再閲覧・再共有できます。

## ビルド方法

```bash
# 依存関係のインストール
flutter pub get

# 実行（開発）
flutter run

# APK ビルド（Android）
flutter build apk --release

# App Bundle ビルド（Google Play）
flutter build appbundle --release

# Windows ビルド
flutter build windows --release
```

> **最低 Flutter バージョン**: 3.x  
> **対応プラットフォーム**: Android, Windows（iOS・macOS はビルド環境次第で対応可能）
