## 주요 기능

### 💰 지출 기록
- 날짜·금액·카테고리·소비수단·메모를 입력해 소비를 기록합니다.
- 월별 달력 뷰와 리스트 뷰를 함께 제공합니다.
- 소비구분(대분류 / 소분류)과 소비수단 태그를 자유롭게 설정할 수 있습니다.

### 🔁 고정지출 관리
- 월세·구독·보험료 등 매달 반복되는 고정비를 별도 관리합니다.
- 월별 고정비 합계와 일반 지출 합계를 분리하여 잔액을 계산합니다.

### 📈 수입 관리
- 월 수입을 등록해 예산 대비 지출 현황을 파악합니다.

### ✈️ 여행 관리
- 여행 모드가 켜지면 홈·소비기록 화면의 기록 버튼이 초록색 **여행지출 기록하기**로 바뀝니다.
- 설정의 **앱 배경**에서 기본 단색 또는 그라데이션 4종을 선택할 수 있습니다. 여행 모드와 무관하게 앱 전체에 적용되며 재실행 시 첫 화면부터 유지됩니다.
- 여행 삭제 시 확인 후 해당 여행의 모든 지출을 **평상시**로 변경하고 여행 정보를 삭제합니다. 지출 금액과 내용은 유지됩니다.
- 여행 기간·예산을 등록하고 여행 모드로 기록한 지출을 여행별로 모아봅니다.
- 여행 카드에서 이름·기간·상태와 총지출, 예산 사용률, 남은 예산 또는 초과 금액을 확인할 수 있습니다. 예산이 없으면 카드에서 바로 설정할 수 있습니다.
- 여행 전·중·후 지출, 하루 평균, 교통비·숙박비와 예산 사용률을 확인할 수 있습니다.

### 🏷️ 소비구분 아이콘
- 시스템 기본 소비구분은 이름과 함께 의미를 나타내는 아이콘을 표시합니다. 아이콘 정보는 태그 메타데이터와 CSV 백업에 함께 저장되며, 구버전 데이터는 소비구분 코드에 맞는 기본 아이콘을 자동으로 적용합니다.

### 📊 분석 리포트
- `fl_chart` 기반 시각화로 지출 패턴을 한눈에 파악합니다.
  - 카테고리별 / 소비수단별 지출 비율 (파이차트)
  - 일별 지출 추세 (라인차트)
  - 최고·최저 지출 일 자동 분석
- 특정 달 또는 날짜 범위를 선택해 조회할 수 있습니다.
- 기간별 분석과 여행별 분석을 전환할 수 있습니다.

### 🗂 데이터 관리
- 검색 조건(소비수단·기간·소비구분·소비 소구분·내용·비고)으로 기록을 필터링합니다.
- 검색 결과를 **일괄 선택 → 삭제** 또는 **태그 일괄 변경**할 수 있으며, 과거 지출을 특정 여행에 한꺼번에 연결할 수 있습니다.
- 2,000건 이상의 대량 데이터도 지연 렌더링(SliverList)으로 부드럽게 표시됩니다.

## 데이터 이사 (내보내기 / 가져오기)

기기를 바꾸거나 데이터를 백업하고 싶을 때 사용합니다.

### 내보내기 절차

1. **데이터 관리** 메뉴에서 **내보내기**를 선택합니다.
2. 내보낼 **기간**을 선택합니다 (전체 / 특정 월 / 날짜 범위).
3. **인증 키**를 입력합니다 (복원 시 동일한 키가 필요합니다).
4. **내보내기** 버튼을 누르면 서명이 포함된 `.csv` 파일이 생성됩니다. 파일 본문은 암호화되지 않습니다.

백업에는 지출·고정지출·수입과 함께 여행 정보, 여행에 연결된 지출, 태그, 알림 및 앱 배경 설정이 포함됩니다. 월·기간 백업에는 선택한 지출이 참조하는 여행만 포함됩니다.
5. 파일을 이메일·클라우드·USB 등 원하는 방법으로 저장합니다.

> 파일은 이메일 주소와 인증 키 조합으로 서명됩니다.  
> 서명이 일치하지 않으면 복원이 차단되므로, **키를 반드시 기록해 두세요.**

### 가져오기 절차

1. **데이터 관리** 메뉴에서 **가져오기**를 선택합니다.
2. 저장해 둔 `.csv` 파일을 선택합니다.
3. 내보낼 때 사용한 **인증 키**를 입력합니다.
4. **가져오기** 버튼을 누르면 기존 데이터와 병합 없이 전체 복원됩니다.

> ⚠️ 가져오기는 현재 데이터를 **덮어씁니다**. 사전에 현재 데이터를 내보내 백업해 두세요.

여행 정보가 없던 구버전 백업도 가져올 수 있으며, 이 경우 여행 목록과 여행 연결 정보는 비어 있는 상태로 복원됩니다. 새 형식의 여행 참조가 손상된 파일은 현재 데이터를 교체하기 전에 거부됩니다.

## PDF 리포트 출력

월 마감·세금 신고·가족 공유 등 다양한 용도로 PDF 리포트를 생성할 수 있습니다.

### 포함 가능한 항목

| 섹션 | 내용 |
|------|------|
| 개요 요약 | 총 수입 / 총 지출 / 잔액 / 고정비 합계 |
| 카테고리별 지출 | 카테고리·소분류별 금액 및 비율 |
| 소비수단별 지출 | 결제 수단별 금액 및 비율 |
| 지출 Top 10 | 가장 큰 소비 항목 10건 |
| 고정지출 상세 | 고정비 전체 목록 |
| 지출 내역 (부록) | 검색된 기간의 전체 거래 내역 |
| 차트 | 카테고리 파이차트, 일별 지출 라인차트 |

### 출력 절차

1. **데이터 관리** 메뉴에서 **리포트 생성**을 선택합니다.
2. 리포트에 포함할 **섹션**을 체크합니다.
3. 조회 **기간**을 설정합니다.
4. 필요하다면 **비밀번호**를 설정합니다 (PDF 열람 시 입력 요구).
5. **생성** 버튼을 누르면 PDF가 만들어지고, **공유** 버튼으로 다른 앱에 전달할 수 있습니다.
6. 생성된 리포트는 **리포트 목록**에 저장되어 언제든 재열람·재공유할 수 있습니다.
