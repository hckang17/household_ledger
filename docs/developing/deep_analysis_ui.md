# 심층분석 UI 미리보기

현재는 2026년 9월의 가공 완료된 예시 결과를 표시한다. 실제 DB 조회·쓰기·분석 계산·광고 요청은 추가하지 않았다.

## 화면

월 지출 합계 → 1/3/6/12개월 월평균 선택 → 증감 구성, 월별 추세, 큰 지출 3건, 고정지출 구성 순서다. 모바일은 1열, 넓은 화면은 2열이며 글자 확대 시 1열로 전환한다. 큰 지출 기록을 누르면 읽기 전용 상세 시트가 열린다.

예시는 6개월의 이전 이력을 갖는다. 12개월은 이력 부족으로 비활성화된다. 비교 기간을 바꾸면 증감 수치·막대, 평균선, 고정지출 평균이 함께 바뀐다. 기준 월은 샘플 월로 고정이며 월 이동 버튼은 제공하지 않는다.

## 데이터 경계

- `DeepAnalysisReport`: 집계가 끝난 금액, 평균, 차이, 비율, 월별 값.
- `deepAnalysisProvider`: 현재는 예시 결과 공급. 실제 계산 단계에서 공급원을 교체한다.
- `DeepAnalysisDashboard`: 결과와 언어팩을 받아 표시. 저장소 접근 없음.
- `DeepAnalysisPage`: 로딩·실패·재시도·결과 연결.

월평균과 차이, 고정지출 평균은 하드코딩한 fixture다. 일반 지출과 고정지출을 합친 월 합계를 기준으로 비중을 표시한다. 상위 3건 합계는 410,000, 제외한 금액은 1,070,000이다. 실제 집계 연결 시 기록 누락, 진행 월, 0원 고정지출 정책을 별도로 구현해야 한다. 현재의 안내는 예시이며 데이터 완전성을 판정하지 않는다.

## 참고한 공식 UI 자료

- YNAB: 총액과 카테고리 비중을 중심으로 한 모바일 Reflect 구성.
  https://www.ynab.com/whats-new/spending-breakdown-on-mobile
- Monarch: 기간 필터와 월별 막대 그래프를 이용한 지출 추세.
  https://www.monarch.com/saved-reports-and-more

공식 UI 소개와 레이아웃 설명을 참고해 앱의 기존 둥근 카드 구조에 맞췄으며 브랜드 자산을 복제하지 않았다.

## 검증

전용 Widget 테스트: 한국어/일본어 320dp·글자 1.8배, 기간 전환, 이력 부족, 상세 시트, 빈 결과, 로딩·오류·재시도, 데스크톱 배치. `DEEP_PREVIEW=1`로 전용 테스트 실행 시 `build/deep_analysis_preview/desktop.png`를 생성한다.
