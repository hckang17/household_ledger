# 월별 심층분석

## 사용자 흐름

분석 화면 → 심층분석 → 월 선택(이번 달 기본값) → 레포트 생성.
진입 시 조회·계산은 없다. 생성 중 월 변경과 중복 클릭을 막고 조회·계산 상태를 구분한다. 실패하면 다시 시도할 수 있다.
월 선택만 변경하면 기존 결과의 월은 바뀌지 않는다. 다시 생성하면 새 결과로 교체한다.

## 데이터와 계산

- `deepAnalysisProvider`: 명시적인 `generate(month)`를 가진 autoDispose AsyncNotifier.
- `deepAnalysisLoaderProvider`: 기준 월과 직전 12개월의 일반·고정지출을 기존 저장소의 기간 조회로 읽는다. 캐시 대신 매 생성마다 최신 데이터를 읽는다.
- `deepAnalysisRunnerProvider`: 네이티브에서는 compute로 계산한다. Web에서 별도 isolate 실행을 보장하지 않는다.
- `calculateDeepAnalysis`: 월별 합계·분류 합계를 한 번 구성한 뒤 비교 기준과 카드를 계산한다. 기존 AnalysisSeriesCalculator를 재사용한다.
- `DeepAnalysisReport`: 불변 목록, 시스템 분류 코드, 고액 지출 ID를 포함한다. 번역과 사용자 태그 표시는 View 책임이다.
- 오래된 실행이나 화면 종료 뒤 완료는 상태에 반영하지 않는다.

완료된 월은 월 전체를 비교한다. 이번 달은 오늘까지 일반 지출과 이전 월의 같은 일자까지를 비교하며 짧은 달은 말일까지 포함한다. 미래 일반 지출은 제외한다. 고정지출은 결제 여부를 추정하지 않고 각 월 등록액 전체를 포함한다.

조회 범위의 첫 기록보다 앞선 월이 필요한 비교는 이력 부족이다. 첫 기록 이후 무기록 월은 0원이다. 기록의 완전성을 판정하지 않는다. 평균은 분류별 정수 반올림 합계이며 증감 구성 합계와 총증감이 일치한다. 상위 3건은 일반 지출만 대상이고 비율의 분모는 고정지출을 포함한 총액이다.

## 표시

공통 집계와 네 카드 계산을 한 worker에서 마친 뒤 결과를 전달한다. 카드마다 별도 조회하거나 연출을 위해 계산을 지연하지 않는다. 준비된 카드는 위치를 유지하며 페이드·이동 효과로 등장하고 시스템 애니메이션 축소 설정을 따른다. 현재 구현은 카드별 worker 중간 결과 스트리밍 방식이 아니다.

비교 선택은 준비된 1·3·6·12개월 결과를 선택한다. 상세는 읽기 전용이다. 예시 결과는 테스트 fixture로 옮겼다.

## 검증

계산: 당월 같은 일자, 미래 기록 제외, 고정지출, 윤년, 연도 경계, 무기록 월, 이력 부족, 빈 결과, 반올림 합계, 불변 목록.
Provider: 진입 시 무조회, 실패·재시도, 최신 실행 우선, 네이티브 compute 전달.
Widget: 한·일 작은 화면·확대 글꼴, 비교 선택, 상세, 빈 결과, 명시적 생성·오류·재시도, 데스크톱 배치.
실기기에서 DB 조회를 포함한 생성 및 프레임 성능은 별도 확인이 필요하다.
