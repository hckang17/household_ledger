# 순서 3: 분석 제어부·달력 현지화 수정

2026-09-16. [후속 지침서](../beta_remediation_and_multidevice_ui_guide.md)의 B04·B08을 수정한다. 순서 1·2의 변경과 증거는 보존했다.

## 변경 내용

- 분석 기간 모드와 월·기간 이동 제어부가 좁은 폭 또는 큰 글자에서 위아래 두 줄로 배치되도록 변경했다.
- 월 범위 문자열은 남은 폭 안에서 한 줄을 유지하고, 이전·다음 화살표의 조작 영역을 보존했다.
- 기간별·여행별 분석 전환은 큰 글자에서 세로 배치되어 일본어·한국어 문구가 단어 중간에서 꺾이지 않게 했다.
- 소비기록 달력의 영어 고정 요일을 제거하고 한국어 `일–토`, 일본어 `日–土` 언어팩 키로 표시한다.

## 자동 검사

- 일본어 320×568dp·글자 1.3에서 월 범위와 이전·다음 화살표 표시 및 조작을 검사한다.
- 일본어 360×640dp·글자 1.8에서 기간 범위와 기간별·여행별 분석 전환을 검사한다.
- 4·5·6주 달력에서 일본어 요일 표시, 날짜 선택, 월 조회, 접기와 화면 크기 변경을 검사한다.
- 한국어·일본어 요일 키의 값과 순서를 검사한다.

## 검사 결과

- 관련 Widget/언어팩 검사 6건 통과
- 전체 Flutter 테스트 153건 통과, 기존 제외 2건
- `flutter analyze` 통과
- Android x64 debug APK 빌드 및 API 36 에뮬레이터 설치 통과
- 한국어·일본어 언어팩 604개 키 집합 일치

## Android 확인

전용 API 36 에뮬레이터에서 density 320으로 검사했다.

- [일본어 320×568dp·글자 1.3 분석 화면](android_analysis_jp_320x568_font13.png): 월 모드와 날짜 범위가 두 줄로 배치되고 이전·다음 화살표가 카드 안에서 표시된다.
- [일본어 360×640dp·글자 1.8 분석 화면](android_analysis_jp_360x640_font18.png): 기간별·여행별 분석과 월 제어부가 세로로 재배치되고 문구가 잘리지 않는다.
- [일본어 360×640dp·글자 1.8 달력](android_calendar_jp_360x640_font18.png): `日–土`가 한 줄로 표시되고 영어 요일과 글자 단위 줄바꿈이 없다.

각 화면의 UIAutomator XML과 실행 요약 `checks.txt`를 같은 폴더에 보관한다. 실물 기기와 한국어 Android 캡처는 추가 검증 범위이며, 한국어 표시는 동일 렌더링 경로와 Widget/언어팩 검사로 확인했다.
